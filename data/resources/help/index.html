Overview

Alcedo is a native GNOME mail client with a unified inbox and contacts. Open this guide anytime from Help → Contents or F1. Question-mark buttons jump to the matching section.

Mail and Contacts are separate spaces. Preferences, accounts, and keyboard shortcuts live under Edit → Preferences (Ctrl+,).

Layout

The far-left app rail switches spaces: Compose, Mail, and Contacts. Hide it with F9 or View → Show app rail.

While Mail is active, the folder pane lists Everything (unified inbox) and any extra views, then this account’s IMAP folders. Mail scope lives here, not on the rail.

  • The message list sits in the middle. Toggle folder visibility from the list header. The Size column is the whole message, including attachments; an em dash means the size is not known until the mailbox sync records it.
  • The reading pane can sit to the right or below the list (layout button in the list header).
  • Drag the splits to resize. Widths are remembered.

Accounts

Add accounts from File → Add Account or Preferences → Accounts.

  • Google and Microsoft sign in with OAuth in your browser. Put client IDs in ~/.config/alcedo/oauth.toml (see oauth.toml.example).
  • Yahoo and generic IMAP use an app password stored in the system keyring, not in Alcedo’s database.
  • Each account has IMAP, SMTP, a display name, a chip (blank for automatic initials, with a background color or a photo cropped to a circle), optional extra From addresses, a signature, and OpenPGP keys.

The folder pane account switcher picks which account’s folders you are browsing. Unified views still combine mail across accounts.

Folders

Right-click a folder to sync, mark all read, search, create a subfolder, empty it, or delete messages on or before a date. Inbox, Sent, Drafts, Junk, and Trash cannot be renamed or deleted.

  • File → New Folder creates a mailbox on the current account.
  • Drag a message onto a folder to move it. Hold Ctrl or right-click-drag to copy.
  • Some servers treat COPY as a move. Gmail copies as expected.
  • F5 syncs the current folder.

Reading mail

  • HTML is shown in a sandboxed view. Remote images stay blocked until you allow the message or sender, unless you turn on Load remote images in Preferences → Privacy.
  • Sign-in codes can appear in a banner for one-click copy. Optionally move that message to Trash after copy.
  • Mailing lists with List-Unsubscribe show an Unsubscribe button.
  • OpenPGP status appears above the body when a message is signed or encrypted.
  • Calendar invitations show Accept, Tentative, and Decline when someone invited you. Your reply is emailed to the organizer. Other invitations show Add to Calendar, which opens them in your calendar app.
  • Click an attachment to open it. Right-click for Save to File…. Types that can run code (configured in Preferences → Privacy) stay stored, but you must confirm before Alcedo enables them.
  • Archive, star, and delete for the open message sit next to Reply on the reader. Selecting several messages shows a toolbar above the list instead.
  • View → Show message previews toggles list snippets. List density (compact / comfortable / relaxed) is in Preferences → General.

Conversations

View → Group by conversation folds replies into threads. Expand a thread in the list to see each message. Turn it off to show one row per message.

Compose

Ctrl+N or Compose on the app rail opens a draft. Reply, Reply All, and Forward are on the Message menu and the reader. Pop the composer into its own window with the window button.

  • Formats: plain text, HTML, and Markdown. Default format is in Preferences → Composing.
  • Account chooses the mailbox that sends. From is the address recipients see. It lists that account’s address and any extra addresses saved on the account.
  • HTML has a formatting toolbar, source view, and image insert. Markdown has a preview.
  • HTML line spacing starts at 1.5, the usual body default in HTML mail. Line spacing sets Single (1), 1.15, 1.5, or Double on the paragraph at the cursor, or on each paragraph in the selection.
  • Attachments: drag files onto the composer. There is a count limit. Inserting an image that some clients cannot display shows a warning; Alcedo still adds it.
  • Ctrl+Enter sends.
  • Drafts sync to the account’s Drafts folder when the server provides one. After send, Alcedo can copy to Sent.

Alcedo handles mailto: links when installed as the default mail app.

From addresses

The composer has an Account row and a From row. Account chooses the mailbox. From starts as that account’s address. Type an address, or open the list, to use a saved extra address. An address you type that is not saved is used for this message only; add it under Preferences → Accounts → From addresses to keep it. Saved addresses are listed there, oldest first. Click a row to edit it, or use the delete button to remove it.

Every email has two “senders”. One is the From address that people see. The other is the address your mail server uses behind the scenes to send the message and to receive any “could not be delivered” replies. Normally the second one is your account address.

The switch “Send from the saved address itself” (Preferences → Accounts → the account → From addresses) controls this. When it is on, and you send from a saved address on the same domain as the account, that saved address is used for both. Replies about failed delivery then come back to that address. When it is off, or when you use a typed address or an address on a different domain, the server still sends as your account address, and Alcedo adds a “Sender” line so the message stays honest about where it came from. You still sign in with the account either way.

This switch is on by default for password accounts. It is off for Gmail and Outlook, because they only accept it if you have set up the extra address with them. Changes to this switch and to Catch-all domains are applied when you press Save at the bottom of the account page.

Gmail and some other providers only send as your account address or an address you have verified with them. If a message is rejected or shows a different From, check the address with your provider.

Snippets & signatures

Snippets are reusable compose inserts. Manage them in Preferences → Composing. In the composer, use the snippets button. Placeholders:

  • {{first_name}} — first word of the first To contact, or the local part of the address
  • {{full_name}} — display name
  • {{email}} — address

Each account has a signature. Toggle “Include signature” on the compose toolbar. Signature format follows the compose format.

OpenPGP

Generate or import a key on the account page under OpenPGP. Private keys and passphrases stay in the system keyring. You can sign outgoing mail by default, and sign or encrypt per message in the composer.

  • Encrypt is available when every recipient has a known public key.
  • Incoming signed or encrypted mail shows a status banner. Autocrypt headers can offer to save a sender’s public key.
  • Export copies your public key to the clipboard.

Message rules

Open Edit → Message Rules or create a rule from a message. Conditions match From, To, Cc, recipient, subject, or attachments. Actions can file, copy, star, mark read/unread, or delete.

  • Rules run on this computer as mail is stored in the Inbox.
  • Rule order matters. Stop processing prevents later rules from running.
  • Drag the handle on a rule, or use Move Up / Move Down, to change processing order. Order is top to bottom.

Contacts

The Contacts space lists people as Approved, Unapproved, or Blocked. Search, filter, multi-select, and group them. Add someone from a message address.

Preferences → Contacts can automatically save outgoing recipients as Unapproved until you keep them.

Privacy

  • Remote images and tracking pixels in incoming HTML are blocked by default.
  • Attachments that may be unsafe to open stay in the message; you confirm before enabling them. The type lists are in Preferences → Privacy.
  • Request read receipts and Insert tracking pixel are off unless you enable them in Preferences → Privacy. Outbound tracking requires an HTTPS pixel URL, and Alcedo discloses it before send.
  • Secrets (passwords, OAuth tokens, API keys, OpenPGP private keys) use the system keyring. Mail metadata lives in a local SQLite database.

Notifications & tray

Close to tray hides the window instead of quitting. The tray icon can show unread count.

Click a notification to open the message; verification notifications can copy the code. Mark as read and Delete act on that message without opening the window. Delete also marks the message read.

Appearance

Preferences → Appearance sets light, dark, or system color scheme, plus accent color. List density and conversation grouping are under General (Message list) and the View menu.

Keyboard & command palette

Ctrl+K (or K when the list is focused) opens the command palette: jump to actions, searches, and operators. It also works while the mail search field is focused.

Remap shortcuts in Preferences → Keyboard. List-focus keys (such as E to archive) apply when the message list has focus, so they do not steal typing in search or compose. F10 opens the main menu. Ctrl+? opens the shortcut list.
